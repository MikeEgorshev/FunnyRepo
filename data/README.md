# Данные

Содержимое `data/` в git не попадает — только этот файл.

## Откуда взять

Датасет организаторов — архив `dataset.zip` (256 МБ) из папки «Резервное позиционирование» на Яндекс Диске: https://disk.yandex.ru/d/DdnscmWTBtzkOQ (ссылка из PDF задачи). Внутри: `data.zip` со 122 прогонами rosbag2, `README.md` с описанием и пакет сообщений `tram_vehicle_msgs/`.

## Где держать

Одну распакованную копию на машину храним **рядом с репозиторием, а не внутри**, чтобы её видели все рабочие копии и агенты:

```
<папка хакатона>/
├── FunnyRepo/            # основной клон
├── FunnyRepo-wt/         # worktree агентов
└── dataset/
    ├── README.md         # README организаторов
    ├── tram_vehicle_msgs/
    ├── data/             # распакованный data.zip: 122 каталога <трамвай>_<hash>/
    └── cache/            # кэш прогонов в .npz (создают скрипты research/)
```

Распаковка:

```bash
cd <папка хакатона>/dataset
unzip dataset.zip && unzip data.zip -d data
```

Скрипты находят `dataset/` сами, поднимаясь вверх по дереву каталогов. Другой путь задаётся переменной `TRAM_DATASET=/путь/к/dataset`.

## Что важно знать заранее

Скорость тележек в данных записана в **км/ч**, хотя README организаторов говорит про м/с. Это и другие особенности данных — в [docs/data.md](../docs/data.md).
