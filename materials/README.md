# Исходные материалы хакатона

Файлы от организаторов и расшифровки созвонов как есть, без нашей обработки. Сводки и выводы из них — в [docs/context/](../docs/context/), разбор данных — в [docs/data.md](../docs/data.md). Снято 26.09.2026.

| Файл | Что это | Откуда |
|---|---|---|
| `task/Резервная одометрия по модели.pdf` | полное описание задачи, критерии, формат сдачи (8 стр.) | чат капитанов и раздел «Задачи» платформы, 25.09 |
| `task/mt-hackathon.ru.txt` | текст сайта хакатона: все треки, таймлайн, FAQ | https://mt-hackathon.ru/, видимый текст страницы |
| `task/platform_submission_form.txt` | поля формы «Загрузка решения» | https://reg.mt-hackathon.ru/submitsolution |
| `official/Положение Хакатон МТ.pdf` | положение хакатона (29 стр.) | ссылка «Положение хакатона» на сайте |
| `official/Расписание Хакатона Московского транспорта.pdf` | расписание хакатона | чат капитанов, 23.09 |
| `dataset/README.md` | README датасета организаторов (в нём ошибка: скорость тележек на деле в км/ч) | `dataset.zip` из PDF задачи |
| `dataset/tram_vehicle_msgs/` | пакет сообщений организаторов в исходном виде (в Humble не собирается: нет `<maintainer>`; исправленная копия — `src/tram_vehicle_msgs/`) | `dataset.zip` |
| `pathgraph/щукинская - таллинская.json`, `pathgraph/таллинская - щукинская.json` | карта пути организаторов по направлениям: точки через 1 м (`x, y, z, tang, curv`) в сетке MGRS | чат капитанов, 25.09, «Pathgraph для задачи» |
| `transcripts/2026-09-25-opening.md` | транскрипт открытия хакатона (метки — МСК) | трансляция VK Видео, faster-whisper large-v3-turbo |

| `chat/tg_captains_chat_organizers.json` | сообщения организаторов и администраторов в чате капитанов трека | Telegram, «Резервная одометрия \| Чат капитанов» |
| `chat/tg_forum_info.json` | объявления организаторов | Telegram, форум «Хакатон Московского транспорта», тема INFO |
| `chat/tg_forum_track_odometry.json` | ответы организаторов в теме трека вместе с вопросами, на которые они отвечают (авторы вопросов обезличены) | тот же форум, тема «Резервная одометрия по модели» |

Время в `chat/*.json` — как в клиенте Telegram (UTC+5), МСК на 2 часа меньше. В выгрузках только сообщения организаторов: сообщения других участников не публикуем. Личные ники модераторов и имена администраторов заменены, официальные контакты оставлены.
