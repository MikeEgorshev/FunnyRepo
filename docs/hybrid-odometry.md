# Hybrid Odometry (Синтез PR #12-14 и EKF Mike)

## Краткое описание решения

Решение объединяет лучшие компоненты двух архитектур:
1. **Каузальная модель тягового привода и продольной динамики** (`IntegratedModel` из PR #12):
   - Апериодический фильтр задержки контроллера 1-го порядка ($\tau = 0.2\text{ с}$, задержка привода $0.4\text{ с}$)
   - Кольцевой буфер команд с точной интерполяцией между дискретными ступенями
   - Ограниченная онлайн-адаптация эффективной тяги `traction_gain` $\in [0.8, 1.2]$ по согласованным измерениям двух тележек
2. **Маршрутный фильтр Калмана и геодезическая привязка** (на базе архитектуры Mike):
   - Разрешённые регламентом GNSS-пачки корректируют координату пути $s$ и коэффициент износа колеса $c$
   - Вектор усиления Калмана по скорости строго $K_v \equiv 0$ — скорость определяется исключительно колёсами и моделью
   - Полноценная логика привязки к остановкам (`_snap`) и тупиковым стрелкам на кольце (`_enter_stub`), предотвращающая срыв траектории на конечных станциях
   - Жёсткая 3D Cartesian трансформация антенны master ($+9.873\text{ м}$ продольно по курсу, $-3.0\text{ м}$ по высоте)
   - Калиброванная задержка вывода скорости $40\text{ мс}$ под тайминги эталона организаторов

## Результаты валидации

### 1. Официальный контрольный прогон организаторов (`30618_88aea4d9`)
* **Velocity RMSE:** **0.0309 м/с** (лучший результат, baseline 0.0312 м/с, PR #12 0.0373 м/с)
* **Velocity MAE:** **0.0185 м/с**
* **3D Position RMSE:** **5.171 м**
* **Конечная ошибка (End):** **6.264 м** (устранена ошибка 48 м в тупике)

### 2. Кросс-валидация на полном датасете (79 бэгов)
* **Velocity RMSE (медиана):** **0.052 м/с** (−12% к baseline Mike)
* **Velocity MAE (медиана):** **0.029 м/с** (−24% к baseline Mike)
* **3D Position RMSE (медиана):** **2.750 м** (лучший результат, baseline 2.910 м, PR #12 3.220 м)
* **Максимальная ошибка (медиана):** **20.420 м** (наименьший выброс)

## Запуск в ROS 2 Humble

```bash
# Запуск гибридной ноды со штатными параметрами
ros2 launch tram_odometry hybrid.launch.py use_sim_time:=true

# Или прямой запуск исполняемого файла
ros2 run tram_odometry hybrid_odometry_node
```
